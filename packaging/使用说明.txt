DarkSort 0.18.0 · 暗黑地牢 1 Mod 管理器

安装版可从桌面或开始菜单运行。便携版请完整解压 DarkSort 文件夹并保留 _internal，然后运行 DarkSort.exe。

升级安装版时，先保存方案并关闭 DarkSort，再运行新版安装包，沿用安装向导显示的原安装目录。方案、设置、历史快照和存档备份会继续从 %LOCALAPPDATA%\DarkSort 读取。使用自定义 --data-dir 启动的用户，请继续沿用原数据目录。

软件自动发现 Steam 游戏和 Workshop。可从「工具」进入「扫描路径」指定位置。
左侧查看详情，中间管理可用 Mod 和计划顺序，右侧查看关联、分组和历史。计划列表顶部优先。
两栏可分别筛选或定位。回车跳到下一项，Shift+回车跳到上一项。Ctrl+F 可搜索可用、计划和暂存。
计划列表蓝线表示优先顺序，绿线表示启用依赖。点击端点、上下箭头或右侧关联卡片可跳转。
跳转时会临时显示被筛掉的目标，点击「返回起点」可恢复之前的列表位置。详情支持打开创意工坊和复制 ID。
左侧「打开工坊」优先用 Steam 打开页面。点旁边的箭头可直接用浏览器或复制工坊链接。
「智能排序」预览分类和移动依据。对应人物的皮肤会排在人物上方。
底部标签可查看排序和扫描提示。右侧「历史」可对比快照并载入方案草稿。
Ctrl+Z 撤销当前方案的编辑，Ctrl+Y 或 Ctrl+Shift+Z 重做。也可从「编辑」菜单查看操作。
「文件 → 生成分享包」会打包当前顺序、暂存、联锁、分组和规则，并附工坊清单。接收方可预览匹配情况并导入为独立方案。
用 Ctrl 或 Shift 多选计划里的 Mod，右键选「联锁选中项」。筛选期间也可以联锁。分散项会先显示完整计划中的位置变化。
联锁支持整组调序和启停。点单个 Mod 仍可看它的详情、打开目录和创意工坊。右键可解除联锁。
多选后右键「分组管理」可新建分组或加入已有分组，右侧可搜索组名和组员。
拖分组头上的六点手柄到「计划顺序」或「可用 Mod」，可按组启停。组头也有整组启停按钮。
通过「⋯」修改分组的名称、颜色和拖入顺序。保存方案后可继续取用，行尾色条会标出所属分组。
组头「⋯ → 保存为分组模板」可导出组合，在别的方案点「载入模板」再复用。待匹配的组员可以右键手动选择本机 Mod。
编辑排序规则时，可以让某个分组、标签或颜色的 Mod 排在指定目标上方。
可从可用 Mod、计划顺序或分组拖入 Mod。拖到目标 A 或 B 可替换该侧，拖到规则列表会补上空着的一侧。
选择规则目标时可搜索原名、别名、Workshop ID 或粘贴工坊链接。按住 Shift 单击可逐项选中或取消，换关键词后已选项继续保留。
右击计划项可带入当前 Mod。两个 Mod 的文件覆盖卡片可带入双方，可用「交换 A/B」调整方向。
点行尾黄标或红标，右侧说明卡会指出游戏用哪份文件、缺了什么或怎么处理。点 Mod 名称可以定位。
点计划标题旁的「警告」或「需处理」筛选对应 Mod，点「全部」恢复列表。
同名路径待确认的情况在「待核实」里。用「忽略…」收起单条或一类，通过「已忽略」恢复。
可用列表的「暂存」用于收集候选。右侧可将选中的项批量加入计划末尾。
「视图」可选择夜幕蓝等主题。

点主界面「AI 助手」打开独立面板。可以直接提问、附日志或选择 AI 排序。
冲突卡片的「问 AI」会把当前说明附进去。使用「发送预览」核对资料，再点发送。
AI 排序经过本地规则校验并显示位置变化。确认后进入方案草稿。
大方案排序会显示已等待时间。DeepSeek 官方接口的排序请求使用快速 JSON 输出。
「提问」会查询当前方案的皮肤、扩展、怪物和相关文件，再让已接入的模型根据资料回答。
输入框上方显示当前方案。可接着问「看看第二个的文件」，也可输入「查 #12 的技能文件」。
「发送预览」可以核对会附带的资料。AI 请求失败时可看到原因和查到的本机资料。
选中 Mod 后点左侧「AI 生成」可生成别名和中文简介，共用同一套 AI 接入设置。
顶部「AI → 批量生成别名与翻译」会为所有已扫描的 Mod 补齐缺少的别名和译文。
底部可看进度、隐藏或停止。批量结果逐批保存，任务结束后会提示。
用顶部「查看批量翻译进度」重新打开进度。中断后再次点击批量生成即可继续补齐。

「应用到存档」选择具体档位，可比较启用顺序或从档位新建方案。
点击「刷新档位」可找到游戏刚生成的存档。
要在第一次进入老路时预载整套 Mod，先退出游戏，再点「带方案开新档」。
核对清单并启动后，在游戏主菜单先新建或选择新档。本次启动的第一个战役会应用这份清单。
进档后等游戏完成一次正常保存，Mod 顺序会随档位保留。
使用「绑定当前方案」可在下次打开档位时显示绑定方案的启用差异。
受支持的 Windows DSON build 28385 档位可在城镇保存并退出游戏后预览应用。
核对目标档位后选择「备份并应用」。原始文件保存在 DarkSort 数据目录。
可从「备份与恢复」检查和恢复匹配的版本。

方案、标签、快照与存档备份位于 %LOCALAPPDATA%\DarkSort
从「工具」菜单可打开数据目录。

# DarkSort v0.17.0

面向 Windows 的《暗黑地牢 1》Mod 管理器。它从 Steam 游戏库和指定目录读取 Mod，按方案组织加载顺序，并支持从选定档位导入或应用顺序。

## 启动

从 GitHub 发布页下载对应版本的安装包，双击按向导安装。默认安装到 `%LOCALAPPDATA%\Programs\DarkSort`，无需管理员权限。安装后可从桌面或开始菜单启动。可在 Windows「设置 → 应用 → 已安装的应用」中卸载，方案和备份保存在单独的数据目录。 [GitHub 发布页](https://github.com/y79330910-crypto/DarkSort/releases/latest)

已安装的用户先保存方案并关闭 DarkSort，再运行新版安装包，沿用向导显示的原安装目录。方案、设置、历史快照和存档备份会继续从 `%LOCALAPPDATA%\DarkSort` 读取。使用自定义 `--data-dir` 启动的用户请沿用原目录。

也可双击项目里的 `启动DarkSort.cmd`。Windows 便携版文件名为 `DarkSort-0.17.0-windows-x64.zip`。完整解压，保留 `_internal`，再运行 `DarkSort.exe`。安装版和便携版都包含运行所需的 Python 和 Qt，并使用同一个默认数据目录。

源码环境需要 Python 3.12+ 和 uv。同步环境后，也可双击 `启动DarkSort源码版.cmd` 运行源码。

```powershell
uv sync --extra dev
uv run darksort
```

## 管理方案

1. 启动后自动扫描 Steam Workshop 和本地 Mod。可从「工具」进入「扫描路径」，指定额外游戏库或 Mod 父目录。
2. 两栏各有搜索框。「筛选」缩小当前列表。「条件」可组合来源、分类和标签，计划列还可按状态过滤。点击条件标签上的 × 即可移除。「定位」用回车和 Shift+回车前后跳转，保留多选。按 `Ctrl+F` 打开「搜全部」，从可用、计划和分组按名称或 Workshop ID 搜索。
3. 中间两栏管理可用 Mod 和计划顺序。双击、拖动或点击「加入」把选中项放入计划。计划顶部优先，支持多选和箭头调序。要拖到计划中的指定位置，请先清除计划筛选并展开计划内的标题。
4. 左侧详情可放大封面、设置标签、颜色和别名，也可打开创意工坊或复制 Workshop ID。名称下方可填写个人备注，离开输入框时保存。双击名称可一起编辑别名、简介和备注。右侧「关联」列出 Mod 关系，「分组」可以保存和重复使用一套 Mod。
5. 「智能排序」预览每个 Mod 的分类、建议位置和依据。确认建议后，点击「保存方案」保留变更。
6. 底部面板显示排序和扫描提示。右侧「冲突」逐条说明提醒，「历史」并排对比当前方案与快照。选中快照可载入方案草稿。「文件」菜单的导入和复制会创建独立方案。

在「编辑」菜单可看到下一步撤销或重做的操作。用 `Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。排序、启停、联锁、分组和规则都按操作记录，保存后仍可以撤销。当前方案保留最近 100 次编辑，切换方案后的恢复可使用历史快照。

拖动三条分隔线可以调整四栏宽度或完全收起一栏。折叠后可以拉回分隔线，也可以从「视图」恢复该栏。栏宽会随本机设置保存。

右击 Mod 默认显示详细选项，可以按用途找到设置前置、关联工坊、卸载等动作。点「返回常用选项」可切换。「视图 → 右键菜单设置…」可分别为可用 Mod、计划顺序和分组成员勾选并排序常用动作，还能选择每次右键默认打开的菜单。

打开「帮助 → 功能与入口…」或按 F1，可以按功能名、菜单文字或用途搜索入口和用法。

方案下拉框旁的「管理方案…」可以预览各份方案的 Mod 顺序、重命名或删除。删除会解除 DarkSort 中关联的档位绑定，已保存的版本可在数据目录的 `deleted-profiles/` 找到并重新导入。

导入方案 JSON 或分享包时，可以在同一个预览框核对来源文件、Mod 数量和前几项 Mod，再确认方案名称。名称默认取文件内的方案名，遇到「默认配置」会优先使用有辨识度的文件名。已有同名时，建议名称会自动加序号。

## 分享方案与复用分组

- 「文件 → 生成分享包」导出当前编辑中的顺序、联锁、分组和排序规则，并附带有创意工坊链接的 `Mod 清单.txt`。接收方从「文件 → 导入分享包」先查看待匹配项，再创建独立方案。同名方案会自动加序号。
- 右侧「分组」的组头「⋯ → 保存为分组模板」将名称、颜色和组员顺序存为文件。在另一个方案点「载入模板」，确认后即可用原有整组启停按钮或拖拽手柄。
- 分享包和模板使用 Workshop ID 跨电脑匹配，对本地 Mod 保留待匹配位置。可在计划里用「匹配…」，或右击未匹配的分组成员选「手动匹配本机 Mod」。同时使用多份同 ID 的工坊安装时，可手动选择对应目录。标签和标记颜色规则使用接收方本机的标记。

有 Workshop ID 的条目可以用左侧「打开工坊」或右键菜单查看页面。Windows 优先交给 Steam，系统拒绝时会尝试默认浏览器。点「打开工坊」旁的箭头可以直接用浏览器或复制链接。

对缺少 ID 的本地副本，右键「关联创意工坊…」，粘贴链接或输入数字 ID。保存后可用 ID 搜索该条目并打开或复制链接。再次编辑时清空输入即可移除关联。关联保存在本机设置中，方案和存档继续使用该 Mod 的本地身份。

「视图」里的「界面主题」提供夜幕蓝、铁炉、余烬、寒霜和羊皮纸。四栏的操作安排参考 RimModManager，表格参考 RimManager。[RimModManager 实机介绍](https://www.xiaoheihe.cn/app/bbs/link/179222904) · [RimManager 界面](https://github.com/SalehBusbait/RimManager#screenshots)

## 本地模组与游戏文件

- 「工具 → 新建空模组」可在游戏的 `mods` 目录建包并打开目录。手动安装的工具也可以存到 DarkSort 的 `manual-tools/`，并记录安装说明。
- 「工具 → 工坊 Mod 转为本地」将工坊文件复制到选中的游戏安装。可同时把当前计划的对应条目切到本地副本，并保留工坊链接。
- 右键「卸载本地 Mod」可核对引用它的方案，并将目录移到 Windows 回收站。需要时可以从回收站还原，再扫描。工坊项可通过「在 Steam 取消订阅」打开对应页面。

- 「工具 → 游戏文件替换」可导入 ZIP、文件夹或散文件。保留汉化、标题背景等资源在包内的相对路径。散文件需要先选择游戏内的目标目录。先预览新增与替换的路径，导入后再选择「启用」。启用前会备份原文件，修改对这份游戏安装的所有档位生效。「停用并还原」恢复原文件并移除该包新增的文件。
- 已扫描的 Mod 可右键「转入游戏文件替换…」。导入副本会收在工具里，工坊原件仍可检查更新。资源有变更时会提示「有更新」，停用后可重新预览并更新副本。要恢复普通管理，可选「移回普通 Mod 列表…」。
- 用右键「从扫描中排除」跳过指定目录，也可以在「工具 → 扫描路径」添加或取消排除。排除按路径及其子目录生效，未排除的旧版 Mod 仍可扫描。

## 查看关联

选中 Mod 后，计划列表左侧的连线指向当前 Mod 的直接关联项。蓝线表示优先顺序，绿线表示启用依赖。点击端点或上下箭头会跳到目标，跨列表的关联可从右侧卡片打开。有多份候选安装时，可以按目录选择。

目标被筛选隐藏时会临时显示，被分组折叠时会展开。右侧的「返回起点」恢复之前的滚动与分组状态。「查看此项关联」以当前查看的 Mod 为新的起点。

## 分组与联锁

用 `Ctrl` 或 `Shift` 多选 Mod，通过右键「分组管理」新建或加入分组。右侧可搜索组名和组员、展开或折叠分组，通过「⋯」编辑名称、颜色和组员顺序。一个 Mod 可以在多个分组里，两栏行尾会显示对应的色条。已存在的计划标题可右键「存为可拖动分组」。

拖动组头的六点手柄，把整个组按组内顺序放进计划的指定位置，或拖回「可用 Mod」停用。组头也提供整组启停按钮。按住单个组员可直接调整组内顺序，也可以拖到计划指定位置。组员右键提供标签、别名、规则、工坊及适用的计划操作。完整联锁会作为一个单元移动，停用后可在分组中整组重新启用。

联锁后，点击其中一个 Mod 可以查看它的详情和打开目录。右键该行还能打开它的创意工坊、编辑别名或手动匹配。

用 `Ctrl` 或 `Shift` 多选计划条目，右键选「联锁选中项」。筛选期间也可联锁。选中的 Mod 分散时，先核对完整计划中挪动后的序号。紫色链扣连起来的 Mod 会一起选中、拖动、排序或停用。右键选「解除联锁」，即可单独操作。右键菜单也可以添加计划标题、批量打标签、标记颜色和修改类型。

候选 Mod 可通过「分组管理」加入分组，组员仍以计划中的启用状态为准。旧方案的暂存会按原条目顺序迁入分组，其中的联锁可从分组整组启用。

可用 Mod 也可以右键进「计划与分组」，多选后直接「加入计划并联锁」，或用「加入计划并设标题…」在新加入的条目上方插入标题。「匹配待定位条目…」可用当前安装匹配计划或分组中的缺项。已经入组的 Mod 可在「分组管理」中定位或移出分组。

右键「设置前置…」为一个 Mod 指定依赖。加入计划时会同时补齐可定位的前置。移出该 Mod 后，前置继续启用。若前置仍被其他计划条目需要，DarkSort 会提示这些条目。

## 智能排序

默认从顶部向下依次为字体、汉化、补丁、扩充与调整、地区与怪物、人物、皮肤、贴图美化。匹配到已启用人物的皮肤排在对应人物上方。同类沿用原有相对顺序，待归类和待定位的条目优先保留原位置。联锁整组移动导致预留位置变化时会显示提示。分类参考资源清单、标题和标签，可在详情修改。

「智能排序」右边的菜单可编辑用户规则，或仅按自定义规则排序。启用的相对位置规则优先于自动建议。预览会指出循环、歧义及需要的依赖。

选择规则目标时可搜索 Mod 原名、别名或 Workshop ID，也可粘贴创意工坊链接。按住 Shift 单击可逐项选中或取消，换关键词后已选项继续保留。右击计划里的 Mod，选择「添加排序规则…」可带入该项。两项之间的文件覆盖提醒可直接带入双方，使用「交换 A/B」调整方向。

「在上方」规则可选具体 Mod、分组、标签或个人标记颜色。例如选择「标签 · 功能拓展」在「分组 · 基础玩法」上方。再次排序会按当前成员重新计算。两个集合共有的成员会在该条规则中跳过。

## 排查冲突

点计划行尾的黄标或红标。右侧说明卡会告诉你发生了什么、涉及谁和可以怎么做。点 Mod 名称即可定位，有多个提醒时可用左右箭头查看。

- 黄色表示已判定的文件覆盖。卡片会写出哪份生效、哪份被覆盖。只查到文件同名同位置时，可在右侧「待核实」查看。
- 红色表示需要处理，例如所需 Mod 未加入，或安装文件缺失。
- 点击标题上的「警告」或「需处理」筛出对应 Mod。点「全部」回到列表。点击「文件与判定依据」查看细节。

右侧「忽略…」可收起这一条，也可批量收起当前的黄色或红色提醒。忽略记录按方案保存，可在「已忽略」逐条或全部恢复。排序时仍会先核对规则。移动 Mod 后，生效方变化的提醒会重新显示。

修改 Mod 文件后，可在右侧「⋯」选择「重新检查文件」。

快捷键包括 `Ctrl+S` 保存、`Ctrl+F` 搜索、`F5` 扫描，以及列表中的 `Ctrl+A`、`Ctrl` 和 `Shift` 多选。`Shift+F10` 可以打开列表右键菜单。

## AI 助手

1. 点主界面「AI 助手」打开独立对话面板。「接入设置」可填写兼容 Chat Completions 的地址、模型 ID 和 API Key。支持 `/v1` 基础地址或完整的 `/chat/completions` 地址。本地免密接口可留空密钥。「测试连接」可验证服务。[OpenAI 官方接口说明](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)
2. 输入问题后点「发送」或按 `Ctrl+Enter`。在冲突卡片点「问 AI」可附带当前提醒。用「发送预览」核对资料，回复后可接着追问。
3. 点「AI 排序」可附带当前方案并补充排序偏好。收到建议后，点「核对排序」查看本地校验和位置变化。确认后更新方案草稿并生成排序前快照。
4. 点「附日志」可打开文件、粘贴日志或载入 DarkSort 日志。发送预览展示经过遮盖的带行号摘录，长日志使用末尾片段。结果可复制或继续追问。

问答、排序和日志的提示词已内置，可在接入设置查看。Windows 可选择加密记住密钥。大方案排序显示已等待时间。DeepSeek 官方接口的排序使用快速 JSON 输出。

在「提问」里可直接问「我加了哪些皮肤？」「哪些原版角色还缺皮肤？」「我加了哪些扩展或怪物 Mod？」。DarkSort 在本机查询和统计，再把相关资料交给已接入的模型回答。输入框上方显示当前使用的方案。要换方案，请使用主窗口左上角的方案下拉框。

可以接着问「第二个是什么」「看看它的技能文件」，也可以用计划序号查询，例如「查 #12 的 project.xml」。资料包含 Mod 内相对路径和文本行号，可在「发送预览」核对。AI 请求失败时会显示具体原因和查到的本机资料，输入的问题可直接重试。

选中 Mod 后，左侧「AI 生成」会用同一套接入设置建议中文简介与短别名。核对原文、编辑并点「保存显示」后，别名和译文会在管理器里显示。搜索支持别名和原名。

顶部「AI → 批量生成别名与翻译」会在后台处理所有已扫描的 Mod，补齐缺少的别名和中文简介。已有内容会保留。作者没有提供简介时只生成别名，长简介使用前 7000 字符。底部可看进度、隐藏进度或停止，顶部「查看批量翻译进度」可重新打开。每批自动保存，运行结束后会提醒，再次运行可继续补齐未完成项。

## 存档管理

新战役可以在第一次进入时直接使用 DarkSort 方案。退出正在运行的游戏，Steam 版保留客户端登录。在主界面点击「带方案开新档…」，核对清单后点击「带方案启动游戏」。在游戏主菜单新建或选择刚建的新档，按正常流程进入。游戏会在本次启动后第一个战役挂载资源前读取清单，游戏内的 Mod 菜单可以跳过。等游戏完成一次正常保存，Mod 顺序就会随该档位保留。

在「带方案开新档」中可展开「启动项」。Steam 版默认读取当前账号的游戏启动项，可以刷新或切换到手动输入。手动参数按游戏安装记在 DarkSort 中，非 Steam 版也可以填写。窗口会预览本次的附加参数。遇到含 `%command%` 的 Steam 包装命令，请在手动输入中填写游戏参数。若参数中已有 `-mod_profile`，本次使用 DarkSort 生成的方案清单。

打开「应用到存档」，选择已经保存的档位或手动打开 `persist.game.json`。「刷新档位」读取游戏新写出的档位。窗口显示档位当前顺序和 DarkSort 计划顺序。点击「从档位新建方案」可导入启用列表，找不到的 Mod 保留为待定位条目。

「绑定当前方案」按档位文件路径记录绑定。再次打开档位时会对比绑定方案，显示仅方案、仅档位、移位和身份待确认的条目。绑定其他方案的档位可点「切换到绑定方案」后继续预览应用。可用「解除绑定」或「改绑当前方案」调整记录。

Windows DSON build **28385** 的受支持档位可预览应用。请在城镇保存并退出游戏，核对目标档位及新增、移位、移除项，再选择「备份并应用」。应用会备份原始文件并校验写入结果。应用后的档位内容与备份记录吻合时，可在「备份与恢复」中直接恢复。

写入验证以隔离副本为基础。其他 DSON build 和可读取的 JSON 支持只读导入。游戏生成的老路初始 JSON 档位也能读取。本地 Mod 的应用需确认其位于已识别游戏的 `mods` 目录，并由唯一的 `project.xml` 标题识别。

## 数据位置

默认数据目录为 `%LOCALAPPDATA%/DarkSort/`。支持读取 v1 至 v6 的方案。v5 保留本地 Mod 的待匹配标识，v6 支持可整组重新启用的联锁分组。

```text
settings.json            路径、排除目录、工坊关联、备注、栏宽、当前方案和主题
profiles/<UUID>.json      可导入导出的方案
deleted-profiles/        已删除方案的备份
history/<UUID>/           方案快照
tags.json                自定义标签
scan-cache.sqlite3        可重建的元数据缓存
save-backups/            按档位存放的原始存档与校验清单
game-file-packs/         导入的游戏资源包副本
save-bindings.json       按档位路径记住选择的方案
ai-settings.json         AI 接入地址、模型 ID 和可选加密密钥
launch-loadouts/         游戏启动时使用的 Mod 清单
darksort.log             启动和错误日志
```

当数据目录含非 ASCII 字符时，DarkSort 将启动清单放在游戏目录的 `.darksort-launches/`，通过游戏可读取的相对路径传入。

隔离运行可用 `uv run darksort --data-dir ./artifacts/manual-test`。加上 `--no-auto-scan` 可跳过启动扫描。

```powershell
uv run python scripts/verify_installation.py
./scripts/build.ps1
```

安装验证只读取发现的游戏和 Mod 元数据，在 `artifacts/` 写入报告。构建脚本会检查打包后程序能否启动，再生成 ZIP。

生成 Windows 安装包时，使用 [Inno Setup 6.7](https://jrsoftware.org/inno-setup/downloads)，并运行 `./scripts/build.ps1 -Installer`。可用 `-InnoCompiler` 指定 `ISCC.exe` 的路径。安装向导的[简体中文翻译](https://github.com/kira-96/Inno-Setup-Chinese-Simplified-Translation)按 MIT 许可分发。
